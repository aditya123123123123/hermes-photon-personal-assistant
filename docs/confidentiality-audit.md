# Confidentiality audit

Local tree, every reachable/reflog commit (including the superseded original commit), commit metadata, and all Git objects including dangling blobs were inspected. Neither gitleaks nor trufflehog was installed; used a redacted regex scanner plus manual review instead. Patterns covered common provider tokens, private keys, secret assignments/JWTs, email, phone/chat IDs, absolute user-home paths, tailnet IPs, operator identity strings, schools and street-address markers. This is a heuristic audit, not proof that arbitrary prose cannot identify someone.

## Findings and fixes

- **Generated bytecode contained absolute local home paths/operator identity.** Removed all repository `__pycache__` directories and `.pytest_cache`. None were tracked. Existing `.gitignore` excludes nested bytecode, Python caches, pytest cache and virtualenv. Subsequent verification uses `PYTHONDONTWRITEBYTECODE=1` and pytest's `-p no:cacheprovider`.
- **Historical author identity:** original commit used a generic contributors identity, not a leaked credential. Rewrote the root commit to the explicitly requested public GitHub noreply identity and set repo-local author/committer settings. The harmless original remains reachable only through local reflog/dangling objects; it was also scanned. No destructive Git object pruning was necessary.
- **Personal-install provenance wording:** removed the source-installation-specific suggestions-file claim from README; replaced it with the actual no-automatic-migration contract.
- **No secret/key/token, real recipient, private email, school/address, tailnet IP or absolute home-path finding remains in source or historical Git blobs.** Masked chat fixtures and reserved example-domain email are synthetic and retained. Requested future repository URL/maintainer and commit identity are intentional public identifiers, retained exactly.
